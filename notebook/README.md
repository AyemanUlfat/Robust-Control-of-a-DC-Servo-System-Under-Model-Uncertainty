# Notebook

`pid_vs_hinfinity_servo.ipynb` loads `config/default.yaml` and walks through:

1. building the plants and controllers
2. simulating the step-plus-disturbance test
3. computing settling time, overshoot, and IAE
4. drawing the four-panel figure from the report

Run it from the `notebooks/` folder after installing `requirements.txt`, or open it from the repository root in Jupyter / VS Code.
